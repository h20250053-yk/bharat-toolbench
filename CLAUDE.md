# BharatToolBench — notes for Claude Code

Multilingual tool-use benchmark on a deterministic, **synthetic** railway environment (12 tools since 3.0; 6 before).
100 semantic tasks × 5 languages (en, hinglish, hi, mr, gu) = 500 items (benchmark version 3.0.0). Version 2.1.0 (tag `v2.1.0-data`) = T01-T75, 375 items,
6 tools (split `v2`). Every item is offered all 12 tools (`offer_all_tools` in config/benchmark.yaml). Gold answers are generated by solvers, never hand-written.
Real station names; all trains, schedules, fares and availability are synthetic. Never describe it as live Indian Railways data.

## Setup
```bash
source .venv/bin/activate          # Linux venv on the GPU server
# Ollama 0.40.18 is the standard server (user-space install in ~/FreeModel/ollama, on PATH). Start it in tmux, only when a local run is requested:
tmux new-session -d -s ollama 'OLLAMA_MODELS=$HOME/FreeModel/models OLLAMA_HOST=127.0.0.1:11434 OLLAMA_NUM_PARALLEL=1 OLLAMA_MAX_LOADED_MODELS=1 ollama serve 2>&1 | tee -a $HOME/FreeModel/ollama-serve.log'
tmux kill-session -t ollama        # stop it (do not touch other tmux sessions). The default ~/.ollama is empty; always set OLLAMA_MODELS.
```
preflight, run_pilot and the pre-run snapshot REFUSE an Ollama server older than 0.40.18; the server version is recorded in every row, pre-run snapshot and manifest.
sudo is not available on this server.

## Scoring: lenient headline, strict sensitivity (benchmark 2.1.0)
`evaluation/tolerance.py` is the single, shared format-tolerance layer (every adapter, every language): it recovers only FORMAT (tag variants,
missing closing tag, JSON repairs, status/field spelling, text tool calls, argument formats, unknown extra argument keys, digit scripts, thinking
text) and never a decision; prose is never turned into an answer. Every recovery is recorded per row. `row["score"]` = lenient (headline),
`row["score_strict"]` = original scorer (lower bound when a run-time recovery was used); report both. Details: `FORMAT_ROBUSTNESS.md`.
Ollama >= 0.40.18 is enforced (0.40.13 and older discard valid tool calls; see FORMAT_ROBUSTNESS.md section 7). The old Qwen 2.5 3B / Llama 3.2 3B runs (Ollama 0.40.3, 8192/1024, no format tolerance) are pilot-only; both 3B models will be re-run.
