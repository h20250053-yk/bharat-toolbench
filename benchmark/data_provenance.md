# Data provenance: what is real, what is synthetic

BharatToolBench uses a **simulated** railway-booking environment. It is **not connected to IRCTC or any live system**,
and its train services are **NOT actual operating Indian Railways services**.

## Real-world anchored (stations only)

`environment/data/stations.json` holds 10 stations. Station identity, name, canonical station code, city and state are
anchored to real stations so that city/station names in Hindi, Marathi, Hinglish and English are natural.

| Code | Station | City | State |
|---|---|---|---|
| NDLS | New Delhi | Delhi | Delhi |
| NZM | Hazrat Nizamuddin | Delhi | Delhi |
| JP | Jaipur Junction | Jaipur | Rajasthan |
| ADI | Ahmedabad Junction | Ahmedabad | Gujarat |
| MMCT | Mumbai Central | Mumbai | Maharashtra |
| PUNE | Pune Junction | Pune | Maharashtra |
| NGP | Nagpur Junction | Nagpur | Maharashtra |
| SBC | KSR Bengaluru City | Bengaluru | Karnataka |
| LKO | Lucknow Charbagh | Lucknow | Uttar Pradesh |
| HWH | Howrah Junction | Kolkata | West Bengal |

* Mumbai Central uses **MMCT** (the obsolete code `BCT` was removed in the world revision).
* No station codes were invented. Codes were checked from memory of the standard Indian Railways code list and
  **should be re-verified against an official source before publication** (not possible offline in this session).
* Aliases (en / hinglish / hi / mr / gu) are benchmark-authored spelling variants for language testing, not an official list.
* Gujarati (`gu`) aliases were added on 2026-11-23 for the Gujarati extension: base names only (for example અમદાવાદ,
  મુંબઈ, પુણે), mirroring the Hindi/Marathi rules. "દિલ્હી" maps to both NDLS and NZM, and case-ended forms such as
  અમદાવાદથી are deliberately not aliases. Adding them changed no gold answer and not the mutable-state hash (only the
  static-data hash in the gold metadata). Spellings still need review by a native Gujarati speaker.
* Two Delhi stations (NDLS, NZM) are kept deliberately so that "Delhi" is ambiguous.

## Synthetic (everything else)

All of the following are generated by `environment/build_world.py` and written to `environment/data/trains.json`
(do not hand-edit; run `python -m environment.build_world`, and `--check` to detect drift):

* **Train IDs** `BTB101`..`BTB130` (deliberately not real train-number-shaped) and **train names** (fictional
  gem/colour-themed names; none intentionally matches a real service).
* **Routes**: geographically plausible corridors over the 10 real stations; each pair of trains (odd = forward,
  even = reverse) shares identical segment distances.
* **Distances**: synthetic plausibility fixtures (rounded, loosely realistic), **not** claims of exact railway distances.
* **Schedules**: origin departure time is a fixed fixture; later stop times are derived from distance at a type-specific
  average speed (premium 82, superfast 66, mail 56, day 66 km/h) plus 5-minute halts, rounded to 5 min. Day offsets
  mark overnight travel. `operating_days` = weekday the train leaves its origin.
* **Fares** (INR, whole-journey, per train and class), rounded to the nearest INR 5 with class minimums:

  | Type | SL | 3A | 2A | CC |
  |---|---|---|---|---|
  | premium | - | 2.20/km | 3.15/km | - |
  | sf (superfast) | 0.70/km | 1.75/km | 2.50/km | - |
  | mail | 0.66/km | 1.65/km | 2.35/km | - |
  | day | - | - | - | 1.60/km |

  Minimums: SL 100, 3A 300, 2A 450, CC 150. Consequently 2A > 3A > SL on every train that offers them. These are
  **not** live or tariff-accurate fares.
* **Availability**: baseline seat counts per (train, class) are fixed fixtures (normal, low 1-3, and sold-out 0).
  No live availability. `env.reset()` restores them.
* **Booking IDs** (`BK0001`, ...) and PNRs are deterministic functions of the booking sequence.
* **Reference time** is pinned to 2026-10-05 09:00 IST; no system clock.

## Change log

* World revision 1: train IDs `90101-90130` -> `BTB101-BTB130`; real-looking/duplicate-of-real names replaced; `BCT` -> `MMCT`;
  distances made symmetric and monotonic (ADI-MMCT 491 km everywhere, NZM-SBC 2400 km, ...); times regenerated from
  speeds; fares regenerated by the rule above; gold regenerated programmatically. Seats and operating days preserved.
