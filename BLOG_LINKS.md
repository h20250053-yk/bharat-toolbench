# Code links for the blog

Links point at the tag `blog-v1`, which marks the published snapshot, with line ranges taken from the files themselves. For links that can never move, replace `blog-v1` by the commit hash after pushing: `sed "s#/blob/blog-v1/#/blob/$(git rev-parse HEAD)/#g" BLOG_LINKS.md`. (A commit cannot contain its own hash, which is why this file uses the tag.)
